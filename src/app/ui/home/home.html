Fuentes Miami

Base de conocimiento técnico tipo Wikipedia — Documentación viva, mantenible y escalable

Introducción

Fuentes Miami es una base de conocimiento estructurada tipo Wikipedia diseñada para centralizar documentación técnica, guías de referencia y mejores prácticas de desarrollo.

La interfaz sigue el patrón clásico de enciclopedia: sidebar izquierda con navegación de temas persistente y contenido principal a la derecha con tipografía optimizada para lectura.

Dato: Construido con Angular 22, Signals, Standalone Components y Control Flow nativo.

Arquitectura del Proyecto

Estructura modular por responsabilidad, escalable y mantenible:

components/

Componentes de UI reutilizables (Layout, Navbar, Cards, Buttons, etc.)

services/

Lógica de negocio y estado compartido (Topics, Content, Auth, Data)

styles/

CSS global, variables, utilidades, temas y diseño system

ui/

Vistas/páginas completas (Home, Article, Search, Settings)

Stack Tecnológico

Angular 22

Standalone components, signals, control flow nativo (@if, @for, @switch)

TypeScript 6

Tipado estricto, inferencia avanzada, template type checking

CSS Nativo

Custom properties, Grid, Flexbox, Container Queries, Cascade Layers

RxJS 7

Programación reactiva, signals interop, operadores modernos

ng-icons

Phosphor Icons — 7000+ iconos SVG, tree-shakable, múltiples pesos

Vitest

Testing unitario rápido, compatible con Vite, APIs modernas
