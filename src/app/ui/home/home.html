Fuentes Miami

Documentación y referencia técnica

Introducción

Fuentes Miami es una base de conocimiento estructurada tipo Wikipedia diseñada para centralizar documentación técnica, guías de referencia y mejores prácticas de desarrollo.

La interfaz está dividida en dos paneles: a la izquierda el indicador de temas (sidebar de navegación) y a la derecha el contenido principal del artículo seleccionado.

Estructura del Proyecto

  • components/ — Componentes reutilizables de UI (Layout, Botones, Cards, etc.)
  • services/ — Servicios y lógica de negocio (Topics, Auth, Data, etc.)
  • styles/ — Estilos globales, variables CSS, mixins y utilidades
  • ui/ — Vistas/páginas completas (Home, Article, Search, etc.)
